# Laboratorio 08 — AFEV

Modelos y comandos de verificación formal desarrollados con NuSMV.

El contenido está organizado por ejercicio:

- `Ejercicio1/`: modelo de dos estados `l1` y `l2`.
- `Ejercicio2/`: comandos interactivos para preparar y simular el modelo.
- `Ejercicio3/`: modelo de autenticación, diagrama de estados y propiedades CTL.

Consulta [COMANDOS.md](COMANDOS.md) para ejecutar los modelos.
